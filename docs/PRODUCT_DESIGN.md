# Product and design direction

状态：设计基线，尚无实现或最终角色资产。产品名 **FocusLit**；首个角色 **圆脸小猫**。

## 产品承诺

陪用户回到自己选定的任务。助手可以坚定执行约定，也应容许思考、阅读、音乐和休息。
不把鼠标活动等同于专注，不承诺治疗效果，不用羞耻或宠物受伤驱动工作。

首个目标用户是 Andrew；验证以下两条真实旅程，再扩展泛用功能。

| 旅程 | 开始时的设定 | 正常行为 | 需要干预 |
| --- | --- | --- | --- |
| 刷题 | 60 分钟，两道动态规划题；Safari 做题、Chrome 查资料 | 题目、算法文档、相关 ChatGPT 对话、指定音乐 | 持续刷 Shorts、娱乐资讯、无关对话 |
| 研究写作 | 3 小时，蝙蝠侠不杀原则与哲学 | 相关 YouTube 分析、康德/功利主义资料、写作对话 | 脱离主题的推荐流和持续娱乐浏览 |

浏览器用途是可修改的偏好，不是固定“Chrome=允许”。研究跨域是正常情况。

## 四个界面足够

1. **桌面猫咪**：陪伴、少量气泡、剩余时间的可选小标记；拖拽跨屏，单击打开时段面板。
2. **时段面板**：模板、具体目标、时长、音乐标签页；开始后显示任务、暂停和结束。
3. **菜单栏**：快速查看剩余时间、每个浏览器监测状态、显示/收起猫咪、暂停/结束。
4. **设置**：语言、干预强度/时间、休息、云分析同意、provider/key、费用与数据清理。

启动默认复用上次模板，空目标提供例子，开始前能看清关闭规则。第一轮 onboarding 只解释
必要的浏览器权限及行为；API 是可选项，不阻塞开始。用户需要完整权限设置时再打开设置。

## 猫咪的性格与造型

**性格：平时慵懒，关键时刻认真；有自己的小脾气，也愿意陪你重新开始。**

- 起点：奶油色/暖灰圆脸猫，大头、短爪、清晰耳朵轮廓。最终毛色在 M2 看实稿再定。
- 表情依靠眼睑、眉线、耳朵、坐姿；缩到 32 px 仍能辨认图标轮廓，桌宠约 80–112 pt。
- 一个小书本或台灯可以承载 FocusLit 的光意象。装饰不能遮住表情或增加无意义闪烁。
- 图标、桌宠和安装图保持同一角色比例；维护表情/动作图谱，不逐张生成不一致的猫。
- 使用原创轮廓与动作；Duo 是“情绪清楚、角色鲜明”的参考，不复刻其外形、颜色或姿势。
- 第一版只做一只猫。资产必须记录来源/许可；临时素材不能成为未声明的正式品牌资产。

| 状态 | 姿态 | 中文示例 | English |
| --- | --- | --- | --- |
| 陪伴 | 趴着看书，间歇眨眼 | 默认无气泡 | No bubble by default |
| 不确定 | 抬头、歪头 | 这个和当前任务有关吗？ | Is this part of your task? |
| 提醒 | 坐起，耳朵朝前 | 我们先回到这道题？ | Back to this problem? |
| 倒计时 | 小爪指着时间，表情坚定 | 15 秒后关闭这个页面 | Closing this tab in 15 seconds |
| 休息/idle | 轻轻探头，然后安静等待 | 还在思考，还是想休息一下？ | Still thinking, or ready for a break? |
| 完成 | 伸懒腰、小幅击掌 | 这一段结束了，休息一下吧。 | Session done. Take a breather. |

回到任务后一句“好，继续。”即可；没有追问、惩罚、失望表情和连环通知。
“疑惑”必须与“已经判定无关”区分，避免表情本身制造错误指控。

## 视觉方向：温暖、清楚、克制

设计 token 起点（实现前仍需测对比度，不把色值当无障碍证明）：

| Token | 初始值/方向 | 使用 |
| --- | --- | --- |
| `surface` | `#FAF7F2`，暖白 | 面板底色 |
| `ink` | `#292524`，炭色 | 主文字与角色轮廓 |
| `muted-ink` | `#68615B` | 次要信息，仍需足够对比度 |
| `accent` | `#B86638`，陶土橙 | 重点与选中态；小字/按钮单独验证对比度 |
| `success` | `#476B58`，柔和绿 | 已完成/可用状态，同时配文字/图形 |
| `warning` | `#8A541F`，琥珀棕 | 提醒，不用整窗红色 |
| 字体 | macOS system UI + 系统中文 fallback | 不下载不必要字体，不模仿营销落地页 |
| 间距 | 4/8/12/16/24/32 pt | 保持节奏，避免小卡片堆叠 |
| 圆角 | 控件约 10，面板约 16 pt | 亲和且不过度玩具化 |

深色主题设计独立 token，跟随系统；浅色猫咪在浅背景、深色背景都需轮廓清楚。
不默认采用大面积玻璃拟态、紫蓝渐变、发光边框、渐变标题、密集卡片和装饰图表。
品牌主要来自猫咪、文案、比例和动作，不来自特效数量。

## 动效与桌面礼仪

- 常规控件过渡约 120–180 ms，表情切换约 180–250 ms，作为调试起点。
- 无连续弹跳或呼吸放大；静止状态不维持高频渲染。眨眼不要求持续动画循环。
- Reduced Motion 使用静态姿态切换；避免闪烁。提醒声音默认关闭。
- 点击/拖动区域不覆盖大块桌面；不能拦截透明区域下方应用的操作。
- 非交互提醒不激活窗口、不夺取输入焦点；菜单栏可完成等价操作。
- 猫咪位置归属于显示器可用区域；断屏后回到可见屏，尊重 Dock、菜单栏和缩放。
- 拖动猫咪不等于点击打开面板；全屏/Spaces 行为在 M1 实测并做成可解释的设置。
- 通知与气泡不重复轰炸。idle 提醒有冷却；锁屏、睡眠、休息不提醒。

## 干预中的选择

第一次不确定时提供“当前任务的资料”“稍后再看”。本次放行作用域可见，默认为当前任务
的当前页面/内容版本；永久放行属于设置，不在疲惫时诱导一键放开整个域名。

明确无关时显示关闭倒计时、简短理由和“这是相关资料”纠正入口。暂停/结束始终可达；
这是用户授权的助手，不是无法退出的家长控制。约定更严格模式可后续扩展，当前不承诺防绕过。

首次关闭前解释：恢复列表只能重新打开链接，未保存的输入不保证恢复。编辑保护优先于关闭。
错误或权限断连直接说“Safari 暂停监测，点此恢复”，不显示仿佛一切正常的绿色状态。

## 双语与无障碍

- UI locale 独立于网页语言；中文 UI 可以分析英文资料，反之亦然。
- 文案集中在 locale catalog，不拼接句子；时间格式、复数、长英文、中文换行需实测。
- 使用语义化控件、可见焦点、合理 tab 顺序和 accessible name；无图标猜谜。
- VoiceOver 可读任务、剩余时间和动作；倒计时不能每秒刷屏朗读。
- 状态不只靠颜色。目标普通文本对比度 ≥4.5:1，重要控件边界/图形 ≥3:1，并实际检查。
- 猫咪隐藏时，菜单栏仍可开始/暂停/结束；拖拽有设置中的位置恢复替代操作。

## 每次 UI PR 的 taste 验收

1. 截图看得出唯一主要操作，用户无需理解模型/协议/工程名词。
2. 同一状态猫咪、菜单栏和面板说的是同一件事。
3. 在真实桌面上看 10 分钟：没有抢焦点、遮挡工作、重复提醒或无意义动效。
4. 附中英文、浅深色、小尺寸、Reduced Motion 的必要证据；交互变化附短录屏。
5. 空状态、无权限、断连、未知、超预算同样有完整文案，不能只美化 happy path。
6. 说明这次删掉了哪些无必要操作或信息；不用“大气、现代、高级”替代具体设计理由。

M2 先验证 60 分钟体验；M5 再做 3 小时长期陪伴。用户反馈与实际打断记录优先于静态 mockup。
